# StudyCanvas v3

This version is additive: it keeps the complete StudyCanvas v2 feature set.

New v3 additions:
- Fit entire board to screen
- Center canvas
- Quick note button
- Focus/search a concept directly
- Double-tap/click empty canvas to create a text card
- Escape exits connection selection
- All v2 features remain: text/headings, images, drawing, math, code, resources, PDFs, tags, search, study mode, PIN lock, themes, undo/redo, backup/restore, multiple boards, pan/zoom, curved connections, local autosave and offline PWA support.
